# Photo Checklist — Hoang Long Homestay

This checklist covers every photo slot on the website. Hand it to your photographer before the shoot.

**Total photos needed: 21**

All photos should be shot in landscape orientation (horizontal), 3:2 ratio, minimum 1200×800 px, JPEG quality 85. Warm, natural light preferred — ideally shot in the morning or late afternoon. Avoid heavy filters.

## After the Shoot

1. Resize all photos to **1200×800 px** (or larger — Next.js will handle resizing).
2. Export as JPEG at **quality 85**. Aim for under 300 KB per file.
3. Place them in the correct folders as listed above.
4. Open each component file referenced in `README.md §3` and update the `src` path from the SVG placeholder to the real JPEG.
5. Remove the `unoptimized` prop from each `<Image>` tag once real JPEGs are in place — this lets Next.js compress and serve them efficiently.
6. Run `npm run build` and check each page to confirm images load correctly.
